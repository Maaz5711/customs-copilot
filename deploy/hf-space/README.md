# Customs Copilot API

The back end of [Customs Copilot](https://github.com/Maaz5711/customs-copilot), an independent open-source tool that finds the Pakistan Customs Tariff code for a product and works out the duty bill.

**Independent project. Not a product of, and not endorsed by, the Federal Board of Revenue, Pakistan Customs or the Government of Pakistan. Decision support only, not legal or customs advice.**

This Space only serves the API; the website is hosted separately. Code: MIT, see the GitHub repository.
