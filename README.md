# Customs Copilot (Pakistan)

An AI agent that finds the right 8-digit PCT code for a product and calculates the full import duty bill
(customs duty, RD, ACD, sales tax, income tax) for FY2026-27 and FY2025-26, with a citation for every number.

Status: in development. See `SPEC.md` for the design and `docs/sources.md` for data sources.

> Not legal advice. Always verify with Pakistan Customs.
