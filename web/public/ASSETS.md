# Third-party assets

The site serves no third-party images, video or models. The home-page story is drawn entirely in code (`web/src/components/story/PortScene.ts` for the 3D version, `PortSketch.tsx` for the flat version).

Fonts are self-hosted at build time by `next/font` (Lexend, Source Sans 3; SIL Open Font License).

History: an earlier version (commit 6870fe6) used six Unsplash-License port photos; they were removed on 2026-10-18 when the story moved to a hand-drafted sketch style.
