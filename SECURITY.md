# Security policy

Please report vulnerabilities **privately** using GitHub's "Report a vulnerability" (Security tab, private security advisories) instead of a public issue. Include steps to reproduce. You will get an answer as soon as the author can respond.

Scope: the code in this repository (API, website, agent). Out of scope: the accuracy of tariff classifications (open a normal issue for that). Never include real API keys or personal data in a report. Design and checklist: `docs/security.md`.
